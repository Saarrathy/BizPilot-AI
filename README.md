# 🚀 BizPilot AI

## AI-Powered Business Management System

BizPilot AI is a full-stack intelligent business management platform designed to simplify business operations using modern web technologies and AI-powered assistance.

The system provides modules for finance tracking, customer management, sales monitoring, inventory control, reports, documents, and AI-based business insights.

# ▶️ Installation & Running

## Backend Setup
cd backend
py -m uvicorn app.main:app --reload

Backend runs at:
http://127.0.0.1:8000
Swagger API:


http://127.0.0.1:8000/docs


---

## Frontend Setup


cd frontend
npm install
npm run dev


Frontend runs at:


http://localhost:5173
